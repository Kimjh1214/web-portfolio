홈소개

어떤 문제를 해결할 수 있는 개발자인가?

웹 개발과 운영을 함께 경험한 실무형 개발자임. 요구사항을 빠르게 파악하고 기존 시스템의 구조와 운영 환경을 분석해 필요한 기능을 구현하고 문제를 개선함.

01. 느리거나 불안정한 웹 시스템

애플리케이션, 서버, 데이터베이스의 병목을 로그와 쿼리, 트래픽 흐름으로 추적함. CBT 시스템 응답속도를 15초에서 3초로 개선하고 동시접속자를 300명에서 1,000명까지 확대함.

02. 운영 중 발생하는 장애와 사용자 문의

Windows/Linux 서버와 IIS, 애플리케이션 로그를 확인해 원인을 좁히고 수정 후 정상 동작까지 검증함. 단순히 장애를 종료하는 것보다 재발 가능성을 줄이는 것을 중요하게 생각함.

03. 개발과 유지보수가 함께 필요한 시스템

ASP/.NET, Java/Spring, PHP, JavaScript, HTML/CSS와 SQL을 활용해 기존 시스템을 빠르게 이해하고 기능 개선과 유지보수를 함께 수행할 수 있음.

04. 데이터와 업무 프로세스가 복잡한 시스템

MSSQL/MySQL 기반 데이터 처리와 쿼리 튜닝 경험을 바탕으로 LMS, CBT, 인사·회계 ERP와 같은 업무 시스템의 기능과 데이터를 관리함.

05. 새로운 기술을 빠르게 적용해야 하는 상황

프로젝트에 필요한 기술은 문서, 기존 소스 분석, 테스트를 통해 빠르게 학습하고 적용함. Spring Framework, UbiReport 등 새로운 기술을 실제 업무에 적용한 경험이 있음.

일하는 방식

문제의 원인을 이해하고 필요한 부분을 개선한 뒤 실제 운영 환경에서 결과를 확인함.

파악

요구사항, 기존 코드, 데이터 흐름과 운영 환경을 먼저 확인해 문제의 범위를 정의함.

개선

불필요한 복잡성을 늘리지 않으면서 안정성, 성능, 사용성을 개선할 수 있는 방법을 선택함.

검증

로그, 데이터, 응답시간과 사용자 동작을 다시 확인해 변경 결과를 검증함.

김준홍
